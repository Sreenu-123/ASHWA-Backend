# 🐎 ASHWA Backend

### Powering the Future of Horse-Riding Training.

**ASHWA Backend** is the server-side component of ASHWA, an AI-powered horse-riding training application built with FastAPI and PostgreSQL.

> 🚧 **STATUS: WORK IN PROGRESS**
>
> The backend is actively under development. Features and functionality may change as the project evolves.

---

## ✨ About

ASHWA Backend powers the mobile application by handling authentication, rider profiles, profile image uploads, and riding-session data.

## 🛠️ Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT Authentication
